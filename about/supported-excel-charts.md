# Supported Excel charts

<p align="center">
<img alt = "flexcel lines of code" src = "../images/flexcel-lines-of-code.png" width = "559" height = "288"/>
</p>

This is a list of all the standard Excel charts. For the chart types
that FlexCel can render, we include an screenshot of a basic chart rendered by Excel and by FlexCel.

## General features

 * Log charts are fully supported
 * Secondary axis are fully supported
 * Reversed axis are fully supported
 * Error bars are fully supported
 * Up/Down bars are fully supported
 * Datatables are **not supported**
 * Trendlines are **not supported**
 * 3-D charts are **not supported**
