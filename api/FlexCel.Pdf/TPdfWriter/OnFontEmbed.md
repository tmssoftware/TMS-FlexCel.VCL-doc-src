# TPdfWriter.OnFontEmbed Event

Use this event if you want to manually specify which fonts to embed into the pdf document\.
Note that this applies for a single PdfWriter instance, to set it for the full application, use [OnFontEmbedGlobal](OnFontEmbedGlobal.md)
