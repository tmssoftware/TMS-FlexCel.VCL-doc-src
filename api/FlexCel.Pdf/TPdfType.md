# TPdfType Enumeration

The variant of pdf that will be created\.

Look at ['Creating pdfa files' in the Pdf Exporting Guide](xref:PdfExportingGuide#creating-pdfa-files) for more information\.


## Syntax

**Unit:** [FlexCel.Pdf](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Standard|0|A normal PDF file\.<br />|
|PDFA1|1|PDF/A\-1a or b  \(http://en\.wikipedia\.org/?title=PDF/A\) Note that PDF/A\-1 generates larger files than PDF/A\-2, and also doesn't support transparency\.<br />You probably shouldn't use PDF/A\-1 unless you have a specific reason to do so, as it is very limited\.<br /><br />"a" or "b" mode is defined depending on the value of [TTagMode](TTagMode.md)\.<br />|
|PDFA2|2|PDF/A\-2a or b\. FlexCel will create smaller files in PDF/A\-2 mode than in PDF/A\-1 mode, so if possible you should try to use PDF/A\-2 instead of A1\. A2 also supports transparency\. In FlexCel case, FlexCel can also sign PDF/A\-2 files, but no PDF/A\-1\.<br /><br />"a" or "b" mode is defined depending on the value of [TTagMode](TTagMode.md)\.<br /><br />Note: PDF/A\-2b files generated by FlexCel are also PDF/A\-2u, but they will identify as PDF/A\-2b\.<br /><br />If you want to identify files as PDF/A\-2u instead, use [TPdfSubType.PDFA2_or_A3u](TPdfSubType.md)\.<br /><br />A file that is both tagged and with Unicode mappings is PDF/A\-2a\.<br />If it is not tagged but has Unicode mappings, it is PDF/A\-2u\.<br />If it is neither tagged nor has Unicode mappings, it is PDF/A\-2b\.<br /><br />As all files generated by FlexCel have Unicode mappings, they are actually PDF/A\-u\.<br />|
|PDFA3|3|PDF/A\-3\. Note that the only difference with PDF/A2 is the ability to embed other files inside the PDF file\.<br />|
|PDFA4|4|PDF/A\-4\. Updates PDF/A to use PDF 2\.0\.<br /><br />Tagging is not required for PDF/A\-4 but recommended\.<br /><br />You can create PDF/A\-4f files just by attaching a file\.<br />Note that PDF/A\-4 \(not f\) allows you to embed other files, only if those are PDF/A files themselves\.<br />If the files you are attaching are all PDF/A, you can force the file to be PDF/A only, not PDF/A\-f with the enum [TPdfSubType.PDFA4Only](TPdfSubType.md)\. FlexCel will not check if the files are PDF/A\. If you use [TPdfSubType.PDFA4Only](TPdfSubType.md) and embed other types of files, the resulting PDF/A will be invalid\.<br />|
