# TPageLayout Enumeration

Viewer settings when the document is opened for the first time\.


## Syntax

**Unit:** [FlexCel.Pdf](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|None|0|Keep the layout as defined by the user\.<br />|
|Outlines|1|Show the Outlines pane when opening the document\.<br />|
|Thumbs|2|Show the thumbs pane when opening the document\.<br />|
|FullScreen|3|Open the document in FullScreen mode\.<br />|
|OptionalContent|4|Show the optional content group panel\.<br />|
|AttachmentPanel|5|Show the attachments panel\.<br />|
