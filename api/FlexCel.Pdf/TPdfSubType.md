# TPdfSubType Enumeration

Use this enum to specify the subtype of PDF/A files generated by FlexCel, when it cannot be determined automatically\.
Don't use this enum unless you need to specify the exact subtype\. Also note that if the type can be determined automatically, FlexCel will use that instead, no matter the value here\.


## Syntax

**Unit:** [FlexCel.Pdf](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Default|0|Let FlexCel decide the best subtype of the PDF/A file\. For example, if the file is tagged, it will be "a"|
|PDFA2\_or\_A3u|1|Use this subtype if you want to identify the file as PDF/A\-2\(3\)u instead of PDF/A\-2\(3\)b\. If the file is not PDF/A\-2\(3\)b, this will throw an exception\. In particular, if the file is tagged \(PDF/A\-2a\), this will throw an exception\.<br />|
|PDFA4Only|2|Use this subtype if you want to identify a file with attachments as PDF/A\-4, not PDF/A\-4f\.<br />Note that to identify a PDF/A\-4 as a PDF/A\-4 without the F, all attachments must be PDF/A as well\.<br />FlexCel will not check if the files you attach are all PDF/A\. If you attach other types of files, the generated PDF will be invalid\.<br />If the generated file is not of type PDF/A\-4, this will throw an exception\.<br />|
