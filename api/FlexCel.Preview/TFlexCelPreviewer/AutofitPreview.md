# TFlexCelPreviewer.AutofitPreview Property

Defines if the page will be automatically zoomed to fit in the preview\. Note that zoom will never be less than 10%% or 400%%\.
If you want to autofit just once, call [AutofitPreviewOnce](AutofitPreviewOnce.md) instead\.
