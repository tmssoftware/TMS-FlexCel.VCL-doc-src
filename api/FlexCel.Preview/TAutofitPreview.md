# TAutofitPreview Enumeration

How the preview will be zoomed\.


## Syntax

**Unit:** [FlexCel.Preview](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|None|0|No autofit\. The value in Zoom is used\.<br />|
|Width|1|Fit to the width of the biggest page in the preview, so it displays without horizontal scroll bars\.<br />|
|Height|2|Fit to the height of the biggest page in the preview\.<br />|
|Full|3|Fit so the biggest page in the preview can be seen at full without scrolling\.<br />|
