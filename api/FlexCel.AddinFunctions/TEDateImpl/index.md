# TEDateImpl Class

Implements the EDate addin function\.
Returns the serial number that represents the date that is the indicated number of months before or after a specified date \(the start\_date\)\.
Use EDATE to calculate maturity dates or due dates that fall on the same day of the month as the date of issue\.
