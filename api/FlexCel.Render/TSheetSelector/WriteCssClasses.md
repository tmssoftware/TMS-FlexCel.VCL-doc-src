# TSheetSelector\.WriteCssClasses Method

This method is in charge of writing the style definitions in the header of the html file\.
Note that when deriving from [TStandardSheetSelector](../TStandardSheetSelector/index.md) you normally do not need to override this method, you can just change the CSS properties of this class\.
You can override this method if you want full control on how to export the classes\.
