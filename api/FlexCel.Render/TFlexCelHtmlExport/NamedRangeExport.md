# TFlexCelHtmlExport.NamedRangeExport Event

Use this event to customize how a named range if exported to the HTML file\. Note that for this event to be called, you first need to set [ExportNamedRanges](ExportNamedRanges.md) = true\. If you want to change the id that will be exported or exclude certain named from being exported, you can do so here\.
