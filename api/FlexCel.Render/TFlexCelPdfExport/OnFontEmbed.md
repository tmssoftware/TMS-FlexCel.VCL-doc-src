# TFlexCelPdfExport.OnFontEmbed Event

Use this event if you want to manually specify which fonts to embed into the pdf document\.



Note that this property applies only to this object\. To change the property for the full application, use [TPdfWriter.OnFontEmbedGlobal](../../FlexCel.Pdf/TPdfWriter/OnFontEmbedGlobal.md)
