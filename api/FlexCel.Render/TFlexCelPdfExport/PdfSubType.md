# TFlexCelPdfExport\.PdfSubType Property

Used with specific values of [PdfType](PdfType.md), when the subtype cannot be deduced automatically\.
You will normally want to leave this property at [TPdfSubType.Default](../../FlexCel.Pdf/TPdfSubType.md)\. Only change it if you are required to create a specific subtype of PDF, which is not what is automatically deduced\.
