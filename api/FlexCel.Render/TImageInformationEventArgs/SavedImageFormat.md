# TImageInformationEventArgs.SavedImageFormat Property

File format in which to save this image\. Do not modify it to keep the default format\.
**Important:** If you want to render the charts as SVG objects instead of PNG bitmaps, you need to set this property to THtmlImageFormat\.Svg\.
