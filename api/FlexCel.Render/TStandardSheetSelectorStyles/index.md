# TStandardSheetSelectorStyles Class

Holds the styles for one of the positions of a [TStandardSheetSelector](../TStandardSheetSelector/index.md)\.


## Syntax

**Unit:** [FlexCel.Render](../index.md)

<pre><code class="lang-delphi hljs">TStandardSheetSelectorStyles = class(TFlexCelObject);</code></pre>

## Properties

|Name|Description|
|---|---|
|[ActiveTab](ActiveTab.md)|Style to be applied to the Active tab\.<br />|
|[ActiveText](ActiveText.md)|Style to be applied to the text of the selected tab\.<br />|
|[Links](Links.md)|Style to be applied to the links in the unselected tabs\. Note that the active tab does not have a link\.<br />|
|[List](List.md)|Style of the list used for the different entries in the selector\. this defaults to "list\-style: none", but you can use something like "list\-style: upper\-roman inside" to for example place roman number on each text\.<br />|
|[Main](Main.md)|Style to be applied to the whole Selector\.<br />|
|[UnselectedTab](UnselectedTab.md)|Style to be applied to a tab when it is not the Active one\.<br />|
|[UnselectedTabHover](UnselectedTabHover.md)|Style to be applied to an unselected tab when you hover the mouse over it\.<br />|
