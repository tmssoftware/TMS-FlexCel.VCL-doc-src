# TStandardSheetSelector\.ReplaceMacros Method

This is an utility method that will replace all the \<\#\.\.\.> macros inside a tag by its values\.
Normally you do not need to call this method, since it is called automatically by [WriteOneCssRule](WriteOneCssRule.md)
