# THtmlHotTrack.RowHeadingStyleRTL Property

Style to apply to the heading rows when in Right\-To\-Left \(RTL\) mode, when the mouse is over a cell\. You can use any css style here\.
Set it to empty if you don't want to highlight the headings\. RTL row headings have the line marker at the left, not the right\.
