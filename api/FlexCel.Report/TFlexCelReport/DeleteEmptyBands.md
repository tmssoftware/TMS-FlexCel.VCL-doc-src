# TFlexCelReport.DeleteEmptyBands Property

Determines if FlexCel will delete or just clear ranges with empty datasets \(0 records\)\.
Note that this property doesn't apply to FIXED bands, those are controlled with [DeleteEmptyBandsFixed](DeleteEmptyBandsFixed.md)
