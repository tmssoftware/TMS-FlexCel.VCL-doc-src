# TXlsFile.OptionsRecalcMode Property

Reads and writes the recalculating options in the file\.
**Note that this only affects the file and how Excel will recalculate, not how FlexCel does its recalculation\.** FlexCel ignores this setting and uses [TExcelFile.RecalcMode](../../FlexCel.Core/TExcelFile/RecalcMode.md) instead\.
