# TXlsFile.PrintNumberOfHorizontalPages Property

If set, the sheet will be printed on at most this number of horizontal pages\. Use 0 to have unlimited horizontal pages while still limiting the vertical pages with [TExcelFile.PrintNumberOfVerticalPages](../../FlexCel.Core/TExcelFile/PrintNumberOfVerticalPages.md)\. \(see ['Preparing for printing' in the Api Developer Guide](xref:ApiDeveloperGuide#preparing-for-printing)\)
