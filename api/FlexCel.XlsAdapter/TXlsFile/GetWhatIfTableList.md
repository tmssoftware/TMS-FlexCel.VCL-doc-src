# TXlsFile\.GetWhatIfTableList Method

Returns a list of the upper cells of the What\-if tables in the page\. You can then use [TExcelFile.GetWhatIfTable](../../FlexCel.Core/TExcelFile/GetWhatIfTable.md) to get the definition of each one\.
