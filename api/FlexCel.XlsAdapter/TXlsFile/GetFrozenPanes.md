# TXlsFile\.GetFrozenPanes Method

Returns the cell that is freezing the window, "A1" if no panes are frozen\.
See also [TExcelFile.FreezePanes](../../FlexCel.Core/TExcelFile/FreezePanes.md) This property can work in different windows depending on the value of [TExcelFile.ActiveWindow](../../FlexCel.Core/TExcelFile/ActiveWindow.md)
