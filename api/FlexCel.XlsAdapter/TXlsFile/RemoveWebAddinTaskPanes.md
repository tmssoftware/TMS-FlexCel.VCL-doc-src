# TXlsFile\.RemoveWebAddinTaskPanes Method

Removes all task pane web add\-ins from the file\. Note that this will only remove the task pane addins\. You can remove the content addins by removing the corresponding objects in the sheet with [TExcelFile.DeleteObject\(Integer\)](../../FlexCel.Core/TExcelFile/DeleteObject.md#texcelfiledeleteobjectinteger)
