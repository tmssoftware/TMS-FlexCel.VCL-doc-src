# TXlsFile\.GetSplitWindow Method

Returns the horizontal and vertical offsets for the split windows\. Zero means no split\.
See also [TExcelFile.SplitWindow](../../FlexCel.Core/TExcelFile/SplitWindow.md) This property can work in different windows depending on the value of [TExcelFile.ActiveWindow](../../FlexCel.Core/TExcelFile/ActiveWindow.md)
