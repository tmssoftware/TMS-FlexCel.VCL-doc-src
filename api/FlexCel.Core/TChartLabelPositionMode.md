# TChartLabelPositionMode Enumeration

How coordinates are stored for a label when it is manually positioned\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|MDFX|0|Relative position to the chart, in points\.<br />|
|MDABS|1|Absolute width and height in points; can only be applied to the mdBotRt field of Pos|
|MDPARENT|2|Owner of Pos determines how to interpret the position data\.<br />|
|MDKTH|3|Offset to default position, in 1/1000 th  of the plot area size\.<br />|
|MDCHART|5|Relative position to the chart, in SPRC\.<br />|
