# TFlxFont.Name Property

Font name\. \(For example, "Arial"\)\. **Important:** When using Excel 2007, if [Scheme](Scheme.md) is different from "None", the font scheme takes precedence over the name\. If for example Name = "Arial" but Scheme is Major and the major font is Calibri, the font will use Calibri\.
