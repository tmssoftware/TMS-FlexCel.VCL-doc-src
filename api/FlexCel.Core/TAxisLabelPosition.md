# TAxisLabelPosition Enumeration

Position of the labels on the axis\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|None|0|This axis has no labels\.<br />|
|LowEnd|1|Labels go at the left of the chart, or to the bottom if axis is vertical\.<br />|
|HighEnd|2|Labels go at the right of the chart, or to the top if axis is vertical\.<br />|
|NextToAxis|3|Labels go next the axis, not to the chart\.<br />|
