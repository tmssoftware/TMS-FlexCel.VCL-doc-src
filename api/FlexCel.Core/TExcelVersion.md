# TExcelVersion Enumeration

Defines which Excel version FlexCel is targeting\. Note that while on v2007 you still can make xls 97 spreadsheets\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|v2007|0|Excel 2007 and up\. This version has a grid of 1048576 rows x 16384 columns\.<br />|
|v97\_2003|1|Versions from Excel 97 to Excel 2003\. Those versions have a grid limited by 65536 rows x 255 columns\.<br />|
