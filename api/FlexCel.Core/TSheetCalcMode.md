# TSheetCalcMode Enumeration

How the file will be calculated by Excel\. This enum doesn't affect FlexCel recalculation\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Manual|0|Manual recalculation\.<br />|
|Automatic|1|Automatic recalculation\.<br />|
|AutomaticExceptTables|2|Automatic recalculation without tables\.<br />|
