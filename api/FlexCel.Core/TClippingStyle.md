# TClippingStyle Enumeration

Can be used to clip into a region instead of drawing on it\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|None|0|Normal draw, this will draw the image\.<br />|
|Include|1|This will include the region into the clipping area, no image will be drawn\.<br />|
|Exclude|2|This will exclude the region from the clipping area, no image will be drawn\.<br />|
