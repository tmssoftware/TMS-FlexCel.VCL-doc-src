# TThemeTextFont.Typeface Property

Specifies the typeface, or name of the font that is to be used\. The typeface is a string  name of the specific font that should be used in rendering the presentation\. If this font is  not available within the font list of the generating application than font substitution logic  should be utilized in order to select an alternate font\. This string can also be "\+mj\-lt" for the major font, and "\+mn\-lt" for the minor font\. To get the typeface name, use [TypefaceName](TypefaceName.md)
