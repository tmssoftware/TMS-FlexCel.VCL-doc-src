# TObjectType Enumeration

A type of object\. Do not confuse this with a type of shape \( [TShapeType](TShapeType.md) \) This does not describe the shape form \(like if it is a rectangle or a circle\) but the shape kind \(for example if it is a comment, an image or an autoshape\)
