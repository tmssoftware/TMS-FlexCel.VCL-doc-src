# TConditionalFormatKind Enumeration

Defines which kind of conditional formatting the rule contains\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Expression|0|When the formula is true, then the conditional format is applied\.<br />|
|CellIs|1|Compares the cell with another cell\.<br />|
|ColorScale|2|The rule is a color scale\.<br />|
|DataBar|3|The rule is data bars\.<br />|
|IconSet|4|The rule uses an icon set\.<br />|
|TopN|5|The rule is a top N\.<br />|
|UniqueValues|6|The rule highlights unique values\.<br />|
|DuplicateValues|7|The rule highlights duplicated values\.<br />|
|ContainsText|8|The rule highlights cells that contain some text\.<br />|
|NotContainsText|9|The rule highlights cells that doesn't contain some text\.<br />|
|BeginsWith|10|The rule highlights cells that beign with some text\.<br />|
|EndsWith|11|The rule highlights cells that end with some text\.<br />|
|ContainsBlanks|12|The rule highlights empty cells\.<br />|
|NotContainsBlanks|13|The rule highlights non empty cells\.<br />|
|ContainsErrors|14|The rule highlights cells that contain errors\.<br />|
|NotContainsErrors|15|The rule highlights cells that don't contain errors\.<br />|
|TimePeriod|16|The rule highlights dates inside a range\.<br />|
|AboveAverage|17|This rule highlights cells which are above or below average\.<br />|
