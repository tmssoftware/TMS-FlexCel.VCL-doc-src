# TImageExportType Enumeration

Defines how you want to export the sheet\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Png|0|Export as png image\. Only the first page of the Excel active sheet will be exported\.<br />|
|Gif|12|Export as gif file\. Only the first page of the Excel active sheet will be exported\.<br />|
|Jpeg|13|Export as jpg file\. Only the first page of the Excel active sheet will be exported\.<br />|
|Tiff|14|Export as multipage tiff\.<br />|
|Fax|15|Export as a black and white multipage tiff ccitt3 compatible with standard fax\.<br />|
|Fax4|16|Export as a black and white multipage tiff ccitt4 compatible with standard fax\.<br />|
