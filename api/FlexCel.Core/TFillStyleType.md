# TFillStyleType Enumeration

Stores the different kind of fill styles for an autoshape or drawing\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|NoFill|0|No fill associated with the shape\.<br />|
|Solid|1|Shape is filled with a solid color\.<br />|
|Gradient|2|Shape is filled with a gradient\.<br />|
|Blip|3|Shape is filled with an image\.<br />|
|Pattern|4|Shape is filled with a pattern\.<br />|
|Group|5|The shape is part of a group, and should inherit its parent fill style\.<br />|
