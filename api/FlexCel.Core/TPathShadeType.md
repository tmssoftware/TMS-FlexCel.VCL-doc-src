# TPathShadeType Enumeration

Enumerates the different gradient modes for a Path gradient\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Shape|0|Gradient follows the shape\. If the shape is a circle it will be circular; if it is a star then it will be a star\-shaped path\.<br />|
|Circle|1|Gradient follows a circular path\.<br />|
|Rect|2|Gradient follows a rectangular path\.<br />|
