# TFlexCelClipboardFormat Enumeration

The file fomats that FlexCel can natively put in the clipboard\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Text|0|File will be copied as text\.<br />|
|Xls|1|File will be copied as xls \(BIFF8\)|
|Html|2|File will be copied as HTML\.<br />Note that if you need more control about the type of html generated, you can use FlexCelHtmlExport\.ExportToClipboard\.<br />|
