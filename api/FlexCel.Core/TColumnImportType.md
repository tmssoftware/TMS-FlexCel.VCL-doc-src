# TColumnImportType Enumeration

Handles how to convert a column from text when importing a text file\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|General|0|Try to convert it to a number, a date, etc\.<br />|
|Text|1|Keep the column as text, even if it can be converted to a number or other things\.<br />|
|Skip|2|Do not import this column\.<br />|
