# IChartLegend.CanOverlapWithChart Property

If true, the chart can overlap the legend\. Note that if [Placement](Placement.md) is different from [TChartLegendPlacement.NotDocked](../TChartLegendPlacement.md)  then CanOverlapWithChart will be false\. But even if not docked, this value can still be false as newer Excel versions allow you to specify this property on its own\.
