# TSheetWindowOptions Enumeration

General options for how sheets display\. In Excel, this settings are located in Tools\->Options\->View in the "Window options" box\.
This options apply only to all the sheets\. For options that apply only to the active sheet see [TSheetOptions](TSheetOptions.md)

## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|HideWindow|0|If true, the workbook window will be hidden\. You will need to go to Window\->Unhide to see it\.<br />|
|MinimizeWindow|1|If true, the workbook window will be minimized\.<br />|
|ShowHorizontalScrollBar|3|If false, the horizontal scroll bar will be hidden\.<br />|
|ShowVerticalScrollBar|4|If false, the vertical scroll bar will be hidden\.<br />|
|ShowSheetTabBar|5|If false, the bar with sheet names at the bottom will be hidden\.<br />|
