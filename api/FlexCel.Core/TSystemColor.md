# TSystemColor Enumeration

System colors\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|None|0|Color is not specified\.<br />|
|DkShadow3d|1|Specifies a Dark shadow color for three\-dimensional display elements\.<br />|
|Light3d|2|Specifies a Light color for three\-dimensional display elements \(for edges facing the light source\)\.<br />|
|ActiveBorder|3|Specifies an Active Window Border Color\.<br />|
|ActiveCaption|4|Specifies the active window title bar color\. In particular the left side color in the color gradient of an active window's title bar if the gradient effect is enabled\.<br />|
|AppWorkspace|5|Specifies the Background color of multiple document interface \(MDI\) applications\.<br />|
|Background|6|Specifies the desktop background color\.<br />|
|BtnFace|7|Specifies the face color for three\-dimensional display elements and for dialog box backgrounds\.<br />|
|BtnHighlight|8|Specifies the highlight color for three\-dimensional display elements \(for edges facing the light source\)\.<br />|
|BtnShadow|9|Specifies the shadow color for three\-dimensional display elements \(for edges facing away from the light source\)\.<br />|
|BtnText|10|Specifies the color of text on push buttons\.<br />|
|CaptionText|11|Specifies the color of text in the caption, size box, and scroll bar arrow box\.<br />|
|GradientActiveCaption|12|Specifies the right side color in the color gradient of an active window's title bar\.<br />|
|GradientInactiveCaption|13|Specifies the right side color in the color gradient of an inactive window's title bar\.<br />|
|GrayText|14|Specifies a grayed \(disabled\) text\. This color is set to 0 if the current display driver does not support a solid gray color\.<br />|
|Highlight|15|Specifies the color of Item\(s\) selected in a control\.<br />|
|HighlightText|16|Specifies the text color of item\(s\) selected in a control\.<br />|
|HotLight|17|Specifies the color for a hyperlink or hot\-tracked item\.<br />|
|InactiveBorder|18|Specifies the color of the Inactive window border\.<br />|
|InactiveCaption|19|Specifies the color of the Inactive window caption\. Specifies the left side color in the color gradient of an inactive window's title bar if the gradient effect is enabled\.<br />|
|InactiveCaptionText|20|Specifies the color of text in an inactive caption\.<br />|
|InfoBk|21|Specifies the background color for tooltip controls\.<br />|
|InfoText|22|Specifies the text color for tooltip controls\.<br />|
|Menu|23|Specifies the menu background color\.<br />|
|MenuBar|24|Specifies the background color for the menu bar when menus appear as flat menus\.<br />|
|MenuHighlight|25|Specifies the color used to highlight menu items when the menu appears as a flat menu\.<br />|
|MenuText|26|Specifies the color of Text in menus\.<br />|
|ScrollBar|27|Specifies the scroll bar gray area color\.<br />|
|Window|28|Specifies window background color\.<br />|
|WindowFrame|29|Specifies the window frame color\.<br />|
|WindowText|30|Specifies the color of text in windows\.<br />|
