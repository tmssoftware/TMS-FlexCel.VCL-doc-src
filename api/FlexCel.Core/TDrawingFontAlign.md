# TDrawingFontAlign Enumeration

Different types of font alignment\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Automatic|0|When the text flow is horizontal or simple vertical same as fontBaseline but for other vertical modes same as fontCenter\.<br />|
|Top|1|The letters are anchored to the top baseline of a single line\.<br />|
|Center|2|The letters are anchored between the two baselines of a single line\.<br />|
|BaseLine|3|The letters are anchored to the bottom baseline of a single line\.<br />|
|Bottom|4|The letters are anchored to the very bottom of a single line\. This is different than the bottom baseline because of letters such as "g," "q," "y," etc\.<br />|
