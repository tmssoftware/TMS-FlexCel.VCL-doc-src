# TXlsBiffVersion Enumeration

The specific Excel version that FlexCel will emulate when reading and saving files\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Excel2007|0|FlexCel will identify itself as Excel 2007 in the generated xls files\.<br />|
|Excel2003|1|FlexCel will identify itself as Excel 2003 in the generated xls files\. It will also ignore the extra information written by Excel 2007 when reading xls files created with it\.<br />|
