# TDataConnectionParameterType Enumeration

Specifies how a parameter is refreshed\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Prompt|0|Prompt the user on each refresh for a parameter value\.<br />|
|Value|1|Use a constant value on each refresh for the parameter value\.<br />|
|Cell|2|Get the parameter value from a cell on each refresh\.<br />|
