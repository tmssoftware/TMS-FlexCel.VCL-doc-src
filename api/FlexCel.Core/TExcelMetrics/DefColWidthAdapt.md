# TExcelMetrics\.DefColWidthAdapt Method

Convert the DEFAULT column width to resolution\-independent\-pixels \(1/96 of an inch\)\. This is different from [ColMult](ColMult.md), that goes in a column by column basis\.
See [Excel Internal Units](xref:ExcelInternalUnits) for more information in Excel internal units\.
