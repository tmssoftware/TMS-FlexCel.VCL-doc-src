# TLinkOption Enumeration

Specifies to which object the label is linked to\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|None|0|Not used\. It means the label is not linked\.<br />|
|ChartTitle|1|This is the chart title\.<br />|
|YAxisTitle|2|This is the caption for the Y\-Axis\.<br />|
|XAxisTitle|3|This is the caption for the X\-Axis\.<br />|
|DataLabel|4|This is a Data Label, linked to a series or a point in the series\.<br />|
|ZAxisTitle|7|This is the caption for the Z\-Axis\.<br />|
