# TImageColorDepth Enumeration

Number of colors for the exported images\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|TrueColor|0|24 bits per pixel, no alpha channel\.<br />|
|TrueColorAlpha|1|32 bits per pixel, 8R, 8G, 8B and 8Alpha\.<br />|
|Color256|5|8 bits per pixel, 256 colors\.<br />|
|BlackAndWhite|10|1 bit per pixel, 2 colors \(black and white\)\.<br />|
