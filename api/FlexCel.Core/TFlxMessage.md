# TFlxMessage Enumeration

## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|CustomPageSize|0|Name of a custom page size\.<br />|
|TxtSeries|1|Text that will be shown on chart legends when no data is assigned\.<br />|
|TxtDefaultTimeAMString|2|Default text to show when AM time string is set to empty on the regional settings dialog from the control panel\.<br />When the default is empty, Excel defaults to AM, while \.NET defaults to an empty string\.<br />As we want to behave the same as Excel, we provide this constant here\.<br />|
|TxtDefaultTimePMString|3|Default text to show when PM time string is set to empty on the regional settings dialog from the control panel\.<br />When the default is empty, Excel defaults to PM, while \.NET defaults to an empty string\.<br />As we want to behave the same as Excel, we provide this constant here\.<br />|
