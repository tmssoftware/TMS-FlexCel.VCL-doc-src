# TDataConnectionHtmlFormat Enumeration

How to handle formatting from the HTML source\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|None|0|Bring data in as unformatted text \(setting data types still occurs\)\.<br />|
|RTF|1|Translate HTML formatting to rich text formatting on the data brought into the worksheet\.<br />|
|All|2|Transfer all HTML formatting into the worksheet along with the data\.<br />|
