# TExcelFile.OptionsRecalcCircularReferences Property

If true, Excel and FlexCel will do iterative calculating over cells with circular references, until [OptionsRecalcMaxIterations](OptionsRecalcMaxIterations.md) is reached or the difference is less than [OptionsRecalcMaxChange](OptionsRecalcMaxChange.md)
