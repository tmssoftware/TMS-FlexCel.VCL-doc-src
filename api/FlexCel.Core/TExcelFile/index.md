# TExcelFile Class

Interface a FlexCel engine has to implement to be used by the other components in the suite like [TFlexCelReport](../../FlexCel.Report/TFlexCelReport/index.md) or [TFlexCelPdfExport](../../FlexCel.Render/TFlexCelPdfExport/index.md)\.


## Remarks

This is an abstract class encapsulating the FlexCel API\. Any implementation on the API must derive from this class\. FlexCel provides an implementation of this interface on the class [TXlsFile](../../FlexCel.XlsAdapter/TXlsFile/index.md) \.
