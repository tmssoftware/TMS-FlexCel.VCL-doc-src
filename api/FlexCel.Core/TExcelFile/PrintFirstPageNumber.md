# TExcelFile.PrintFirstPageNumber Property

Page number that will be assigned to the first sheet when printing\. \(So it will show in page headers/footers\)\.
You might set this value to null to keep the page automatic\. Also, the value returned here will be null it this value is not set \(Set to Automatic\)
