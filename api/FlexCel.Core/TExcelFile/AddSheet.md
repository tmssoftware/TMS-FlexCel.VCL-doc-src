# TExcelFile\.AddSheet Method

Inserts an empty sheet at the end of the file\. This is equivalent to calling InsertAndCopySheets\(0, SheetCount \+ 1, 1\)\.
If you need to insert more than one sheet, or insert it at the middle of existing sheets, use [InsertAndCopySheets\(Integer, Integer, Integer\)](InsertAndCopySheets.md#texcelfileinsertandcopysheetsinteger-integer-integer) instead\.
