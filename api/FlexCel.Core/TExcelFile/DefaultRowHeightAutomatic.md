# TExcelFile.DefaultRowHeightAutomatic Property

When this property is true, the row height for empty rows is calculated with the height of the "Normal" font and will change if you change the Normal style\. When false, the value in [DefaultRowHeight](DefaultRowHeight.md) will be used\.
