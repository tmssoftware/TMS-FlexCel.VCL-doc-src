# TExcelFile\.GetSplitWindow Method

Returns the horizontal and vertical offsets for the split windows\. Zero means no split\.
See also [SplitWindow](SplitWindow.md) This property can work in different windows depending on the value of [ActiveWindow](ActiveWindow.md)
