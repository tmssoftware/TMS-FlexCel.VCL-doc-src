# TExcelFile.SheetZoom Property

Reads/Writes the zoom of the current sheet\. Note that this property refers to the zoom in the current page view mode\.
If you are for example in Page Break Preview mode, this would be the zoom for Page Break Preview\. You can change of page view mode and the zoom for all of the modes with [SheetView](SheetView.md) This property can work in different windows depending on the value of [ActiveWindow](ActiveWindow.md)
