# TExcelFile.SheetView Property

Returns and sets the page view mode with their corresponding zooms\. Note that changing the zoom here changes [SheetZoom](SheetZoom.md) This property can work in different windows depending on the value of [ActiveWindow](ActiveWindow.md)
