# TExcelFile.ShowGridHeadings Property

True is the column headings \("A", "B", etc\) and row headings \("1", "2", etc\) are shown\. You can also set this option with [SheetOptions](SheetOptions.md) by changing TSheetOptions\.ShowRowAndColumnHeaders This property can work in different windows depending on the value of [ActiveWindow](ActiveWindow.md)
