# TExcelFile\.GetFrozenPanes Method

Returns the cell that is freezing the window, "A1" if no panes are frozen\.
See also [FreezePanes](FreezePanes.md) This property can work in different windows depending on the value of [ActiveWindow](ActiveWindow.md)
