# TExcelFile.ColCount Property

Number of columns actually used on the active sheet, including formatted columns\.
You will normally want to use [ColCountOnlyData](ColCountOnlyData.md) instead\.
**Note that this method is slow** as it needs to loop over all the rows to find out the biggest used column\. **Never** use it in a loop like "for \(int  col = 1; col \<= xls\.ColCount; col\+\+\)"\. Instead try to use [ColCountInRow\(Integer\)](ColCountInRow.md#texcelfilecolcountinrowinteger)\.
