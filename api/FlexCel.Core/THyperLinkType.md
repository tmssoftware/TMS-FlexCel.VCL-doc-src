# THyperLinkType Enumeration

Possible types of cell hyperlinks\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|URL|0|Web, file or mail URL\. \(like http://, file://, mailto://, ftp://\)|
|LocalFile|1|A file on the local disk\. Not an url or unc file\.<br />|
|UNC|2|Universal Naming convention\. For example: \\\\server\\path\\file\.ext|
|CurrentWorkbook|3|An hyperlink inside the current file\.<br />|
