# TUISize Record

A platform independent Size structure\. Width and Height are floating point numbers\.


## Syntax

**Unit:** [FlexCel.Core](../index.md)

<pre><code class="lang-delphi hljs">TUISize = record;</code></pre>

## Methods

|Name|Description|
|---|---|
|[Create](Create.md)|Creates a new size with the specified width and height\.<br />|


## Operators

|Name|Description|
|---|---|
|[Equality](op_Equality.md)|Adapts the = operator so it returns true when both instances have the same values\.|
|[Inequality](op_Inequality.md)|Adapts the \<> operator so it returns true when both instances have different values\.|


## Properties

|Name|Description|
|---|---|
|[Empty](Empty.md)|Returns a size with width = 0 and height = 0\.<br />|
|[Width](Width.md)|Width from the size\.<br />|
|[Height](Height.md)|Height from the size\.<br />|
