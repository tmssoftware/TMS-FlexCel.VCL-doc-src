# THtmlFileFormat Enumeration

How the html page will be saved\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Html|0|File will be saved as an html file with external images\.<br />|
|MHtml|1|File will be saved in MHTML \(Mime HTML\) file format with all the data inside a single file\.<br />This format is the one used to encode emails\.<br />|
