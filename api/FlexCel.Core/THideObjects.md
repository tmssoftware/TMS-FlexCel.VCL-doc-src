# THideObjects Enumeration

Defines how objects are shown on the file\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|ShowAll|0|ActiveX objects, OLE objects, and drawing objects are displayed in the workbook\.<br />|
|ShowPlaceholder|1|Placeholders are displayed in place of ActiveX objects, OLE objects, and drawing objects in the workbook\.<br />|
|HideAll|2|ActiveX objects, OLE objects, and drawing objects are not displayed in the workbook\.<br />|
