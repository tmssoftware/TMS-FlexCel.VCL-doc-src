# TProtection\.SetSheetProtection Method

Protects a sheet\. On Excel goto Protect\->Sheet to check it\.


## Syntax

**Unit:** [FlexCel.Core](../index.md)

<pre><code class="lang-delphi hljs">procedure <a href="../TProtection/index.md">TProtection</a>.SetSheetProtection(const sheetPassword: string; const sheetProtectionOptions: <a href="../TSheetProtectionOptions/index.md">TSheetProtectionOptions</a>);</code></pre>

## Parameters

|<->|Parameter|Type|Description|
|---|---|---|---|
|const|**sheetPassword**|string|Password to protect the active sheet\. You can set it to null to clear it\.|
|const|**sheetProtectionOptions**|[TSheetProtection&#8203;Options](../TSheetProtectionOptions/index.md)|The options to protect\.|
