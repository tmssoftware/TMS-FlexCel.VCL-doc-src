# TProtection\.SetWorkbookProtection Method

Protects the workbook\. On Excel goto Protect\->Workbook to check it\.


## Syntax

**Unit:** [FlexCel.Core](../index.md)

<pre><code class="lang-delphi hljs">procedure <a href="../TProtection/index.md">TProtection</a>.SetWorkbookProtection(const workbookPassword: string; const workbookProtectionOptions: <a href="../TWorkbookProtectionOptions/index.md">TWorkbookProtectionOptions</a>);</code></pre>

## Parameters

|<->|Parameter|Type|Description|
|---|---|---|---|
|const|**workbookPassword**|string|Password to protect the file\. You can set it to null to clear it\.|
|const|**workbookProtectionOptions**|[TWorkbookProtection&#8203;Options](../TWorkbookProtectionOptions/index.md)|The options to protect\.|
