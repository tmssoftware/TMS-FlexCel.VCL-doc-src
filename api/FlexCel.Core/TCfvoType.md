# TCfvoType Enumeration

Type of a Value\-Object for a conditional format\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Num|0|A number\.<br />|
|Percent|1|The minimum value in the range of cells that the conditional formatting rule applies to plus X percent of the difference between the maximum and minimum values in the range of cells that the conditional formatting rule applies to\.<br />|
|Max|2|The maximum value from the range of cells that the conditional formatting rule applies to\.<br />|
|Min|3|The minimum value from the range of cells that the conditional formatting rule applies to\.<br />|
|Formula|4|A formula\.<br />|
|Percentile|5|The minimum value of the cell that is in the X percentile of the range of cells that the conditional formatting rule applies to\.<br />|
|AutoMin|6|Only available in Excel 2010 or newer\. The smaller of zero or the minimum value from the range of cells that the conditional formatting rule applies to\.<br />|
|AutoMax|7|Only available in Excel 2010 or newer\. The larger of zero or the maximum value from the range of cells that the conditional formatting rule applies to\.<br />|
