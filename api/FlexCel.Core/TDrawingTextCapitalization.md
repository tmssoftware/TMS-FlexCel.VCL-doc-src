# TDrawingTextCapitalization Enumeration

how text is capitalized when rendered\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|None|0|No capitalization\.<br />|
|Small|1|Apply small caps to the text\. All letters are converted to lower case\.<br />|
|All|2|Apply all caps on the text\. All lower case letters are  converted to upper case even though they are stored  differently in the backing store\.<br />|
