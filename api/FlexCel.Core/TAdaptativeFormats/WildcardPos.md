# TAdaptativeFormats.WildcardPos Property

Position of the last wildcard \("\*"\) character in the format \(0 based\)\. If a wildcard is present in the format, the string has to be expanded with the character at position until it fits the width of the cell\.
A negative value means there is no wildcard in the format\.
