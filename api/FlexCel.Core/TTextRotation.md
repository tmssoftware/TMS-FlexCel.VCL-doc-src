# TTextRotation Enumeration

Text direction for objects like comments, that allow rotation, but only in 90 degrees\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Normal|0|Text is not rotated\.<br />|
|Rotated90Degrees|1|Text is rotated 90 degrees counterclockwise\.<br />|
|RotatedMinus90Degrees|2|Text is rotated 90 degrees clockwise\.<br />|
|Vertical|3|Text is written in vertical layout, a character below the other\.<br />|
