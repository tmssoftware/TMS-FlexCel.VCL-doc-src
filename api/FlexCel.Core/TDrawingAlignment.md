# TDrawingAlignment Enumeration

Specifies the alignment types for text in a drawing\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Left|0|Align text to the left margin\.<br />|
|Center|1|Align text in the center\.<br />|
|Right|2|Align text to the right margin\.<br />|
|Justified|3|Align text so that it is justified across the whole line\. It is smart in the sense that it does not justify sentences which are short\.<br />|
|JustLow|4|Aligns the text with an adjusted kashida length for Arabic text\.<br />|
|Distributed|5|Distributes the text words across an entire text line\.<br />|
|ThaiDist|6|Distributes Thai text specially, because each character is treated as a word\.<br />|
