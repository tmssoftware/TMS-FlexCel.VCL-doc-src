# TStyleCategory Enumeration

Category to which a cell style belongs\. This is only valid for Excel 2007 or newer\.

**Unit:** [FlexCel.Core](index.md)

|Custom|0|Custom style\.<br />|

|TitleHeading|3|Title and heading style\.<br />|
|ThemedCell|4|Themed cell style\. \(ACCENT styles\)|
