# TCheckboxState Enumeration

## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Unchecked|0|Checkbox is not checked\.<br />|
|Checked|1|Checkbox is checked\.<br />|
|Indeterminate|2|Checkbox is not set\. An indeterminate control generally has a shaded appearance\.<br />|
