# TChartTrendlineType Enumeration

Defines the type of trendline\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Exponential|0|A best\-fit line that matches an exponential curve of type "y = a \* b^x"\.<br />|
|Linear|1|A best\-fit straight line that is used with simple linear data sets\. The equation is "y = a \* x \+ b"|
|Logarithmic|2|A best\-fit curved line that matches a logarithmic curve\. The equation is "y = a \* log\(x\) \+ b"|
|MovingAverage|3|Moving average trendline\. It will adapt depending on the period you choose\.<br />|
|Polynomial|4|A best\-fit curve generated with a polynomial of order n like "y = a \* x^2 \+ b \* x \+ c"\.<br />|
|Power|5|A curve matching "y = a \* x^b"\.<br />|
