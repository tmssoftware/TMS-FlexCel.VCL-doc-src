# TFlxAnchorType Enumeration

How an image behaves when inserting/copying rows/columns

## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|MoveAndResize|0|Move and resize the image with the sheet\.<br />|
|MoveAndDontResize|2|Move the image when inserting/copying, but keep its size\.<br />|
|DontMoveAndDontResize|3|Keep the image fixed on the sheet\.<br />|
