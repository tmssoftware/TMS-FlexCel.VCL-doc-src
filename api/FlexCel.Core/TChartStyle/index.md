# TChartStyle Record

This structure defines the default style of a chart\. Excel defines 48 default styles\.


## Syntax

**Unit:** [FlexCel.Core](../index.md)

<pre><code class="lang-delphi hljs">TChartStyle = record;</code></pre>

## Methods

|Name|Description|
|---|---|
|[Create](Create.md)|Creates a new chart style\.<br />|


## Properties

|Name|Description|
|---|---|
|[Id](Id.md)|Returns the Style Id, between 1 and 48\.<br />|
|[IdExtended](IdExtended.md)|Returns the Id and adds 100 if is it extended\.<br />|
|[IsExtended](IsExtended.md)|Returns true if this is an extended style, used in Excel 2013 or newer\.<br />|
