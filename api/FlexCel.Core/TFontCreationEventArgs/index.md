# TFontCreationEventArgs Class

Base class for font creation events\.


## Syntax

**Unit:** [FlexCel.Core](../index.md)

<pre><code class="lang-delphi hljs">TFontCreationEventArgs = class(TFlexCelObject);</code></pre>

## Constructors

|Name|Description|
|---|---|
|[Create](Create.md)|Creates a new instance of the event arguments with the specified parameters\.<br />|


## Properties

|Name|Description|
|---|---|
|[FontName](FontName.md)|Name of the font\. Change this value to create a font with a different name\.<br />|
|[FontSize](FontSize.md)|Size in points of the font\. Change this value to create a font with a different size\.<br />|
|[FontStyle](FontStyle.md)|Style of the font \(italics, bold, etc\.\)\. Change this value to create a font with a different style\.<br />|
