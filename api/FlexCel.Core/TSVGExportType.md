# TSVGExportType Enumeration

Customized what data will be included in an svg file\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|All|0|The SVG created will have everything, including the xml declaration and the svg tag\.<br />|
|NoXmlDeclaration|1|The SVG created will not have an xml declaration\. Use this one to embed the svg in other documents\.<br />|
