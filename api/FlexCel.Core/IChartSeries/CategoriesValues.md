# IChartSeries.CategoriesValues Property

Actual values for the Series Categories \(normally the x Axis\)\. Note that category axis can contain multi\-level labels\. In those cases, CategoriesValues will just report all levels separated by carriage returns\.
To see the different levels as an array, use [CategoriesValuesArray](CategoriesValuesArray.md)
