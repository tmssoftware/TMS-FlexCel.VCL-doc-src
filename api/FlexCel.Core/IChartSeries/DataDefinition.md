# IChartSeries.DataDefinition Property

Formula defining the series\. For example, "=A1:A5"\. Start with an "=" sign to enter a formula\.
Note that if the Series doesn't have a formula and only values \(for example \{1,2,3\}\), this property will be null and the result will be in [DataValues](DataValues.md)
