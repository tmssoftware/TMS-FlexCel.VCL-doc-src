# TFlxFormat\.CreateStandard2007 Method

Returns a standard TFlxFormat for Excel 2007\. \(Font name is Calibri, etc\)\. You will normally want to use [TExcelFile.GetDefaultFormat](../TExcelFile/GetDefaultFormat.md) instead of this, since it returns the default format for an specific file, and not a generic format like this\.
