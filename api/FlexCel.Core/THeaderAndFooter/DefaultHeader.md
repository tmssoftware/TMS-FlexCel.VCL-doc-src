# THeaderAndFooter.DefaultHeader Property

Returns or sets the header for all pages that are not even or the first page\. If [DiffFirstPage](DiffFirstPage.md) is false, then this string also applies to the first page\. If [DiffEvenPages](DiffEvenPages.md) is false, this string also applies for even pages\.
For a description of the possible values of this string, see [TExcelFile.PageHeader](../TExcelFile/PageHeader.md)
To set a header for all pages, use [SetAllHeaders](SetAllHeaders.md)
