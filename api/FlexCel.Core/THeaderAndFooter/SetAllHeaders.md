# THeaderAndFooter\.SetAllHeaders Method

Sets the headers for all the pages to a given string\. **Note that setting this value will  set [DiffEvenPages](DiffEvenPages.md) and [DiffFirstPage](DiffFirstPage.md) to false\.** For a description of the possible values of this string, see [TExcelFile.PageHeader](../TExcelFile/PageHeader.md)
