# TPenAlignment Enumeration

Specifies the alignment to be used for the underline stroke\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Center|0|Center pen \(line drawn at center of path stroke\)\.<br />|
|Inset|1|Inset pen \(the pen is aligned on the inside of the edge of the path\)\.<br />|
