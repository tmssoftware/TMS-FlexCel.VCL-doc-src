# TSheetProtectionOptions.Objects Field

If TRUE, objects on the sheet are protected\. Note that this setting behaves like [Scenarios](Scenarios.md) and opposite from all the rest\.
In the other settings, FALSE means that the setting is protected, TRUE that the setting can be changed\.
