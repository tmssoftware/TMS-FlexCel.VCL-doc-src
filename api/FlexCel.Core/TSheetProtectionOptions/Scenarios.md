# TSheetProtectionOptions.Scenarios Field

If TRUE, scenarios on the sheet are protected\. Note that this setting behaves like [Objects](Objects.md) and opposite from all the rest\.
In the other settings, FALSE means that the setting is protected, TRUE that the setting can be changed\.
