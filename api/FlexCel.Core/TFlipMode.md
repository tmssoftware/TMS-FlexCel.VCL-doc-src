# TFlipMode Enumeration

How an image will be flipped when filling a pattern\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|None|0|Image will not be flipped\.<br />|
|X|1|Tiles are flipped horizontally\.<br />|
|Y|2|Tiles are flipped vertically\.<br />|
|XY|3|Tiles are flipped horizontally and vertically\.<br />|
