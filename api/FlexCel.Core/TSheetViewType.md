# TSheetViewType Enumeration

The page mode of a sheet\. You select this in Excel by changing the icons at the bottom right, or from the ribbon, in the "View" tab\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Normal|0|Normal spreadsheet mode\.<br />|
|PageLayout|1|A preview of where pages will break when the document is printed\.<br />|
|PageBreakPreview|2|Document as it will appear on the printed page\.<br />|
