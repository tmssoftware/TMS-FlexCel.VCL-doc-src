# TFullRecalcOnLoadMode Enumeration

Defines how FlexCel will save the files so they will be recalculated or not when you open them in Excel\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Automatic|0|Will set the file to do a full recalc on load only if the file wasn't recalculated by FlexCel\.<br />|
|AlwaysRecalc|1|Will set the file to always do a full recalculation when opened in Excel\.<br />|
|NeverRecalc|2|Will set the file to not do a full recalculation when opening the file\.<br />|
