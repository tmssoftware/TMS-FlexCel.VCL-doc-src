# TDataValidationDataType Enumeration

Possible types of data validation\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|AnyValue|0|All values are allowed\.<br />|
|WholeNumber|1|The value must be an integer\.<br />|
|Decimal|2|The value must be a decimal\.<br />|
|List|3|The value must be in the list\.<br />|
|Date|4|The value must be a Date\.<br />|
|Time|5|The value must be a Time\.<br />|
|TextLenght|6|The value will be validated depending on the text length\.<br />|
|Custom|7|The value will be validated depending on the results of a formula\.<br />|
