# TColorType Enumeration

Defines which one of the values stored in a [TExcelColor](TExcelColor/index.md) structure is the one that must be used\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Automatic|0|Color is Automatic\.<br />|
|RGB|1|The structure contains an indexed color\.<br />|
|Theme|2|The structure contains a themed color\.<br />|
|Indexed|3|The structure contains an indexed color\.<br />|
