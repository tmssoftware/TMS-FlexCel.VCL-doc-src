# TChartErrorBarBarType Enumeration

Specifies the possible ways to draw an error bar\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|None|0|No error bars are drawn\.<br />|
|Both|1|Specifies that error bars shall be shown in the positive and negative directions\.<br />|
|Plus|2|Specifies that error bars shall be shown in the positive direction only\.<br />|
|Minus|3|Specifies that error bars shall be shown in the negative direction only\.<br />|
