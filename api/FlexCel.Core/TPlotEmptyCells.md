# TPlotEmptyCells Enumeration

Defines how empty cells will be plotted in the chart\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|NotPlotted|0|The cell will not be plotted\. There will be a gap in the chart\.<br />|
|Zero|1|The cell will be plotted with value = 0\.<br />|
|Interpolated|2|The cell will be plotted with value interpolated between its nearest points\.<br />|
