# TListBoxSelectionType Enumeration

Types of selection allowed in a listbox\.


## Syntax

**Unit:** [FlexCel.Core](index.md)

## Members

|Name|Value|Description|
|---|---|---|
|Single|0|The list control is only allowed to have one selected item\.<br />|
|Multi|1|The list control is allowed to have multiple items selected by clicking on each item\.<br />|
|Extend|2|The list control is allowed to have multiple items selected by holding the CTRL key and clicking on each item\.<br />|
