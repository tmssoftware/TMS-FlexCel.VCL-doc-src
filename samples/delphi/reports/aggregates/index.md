# Aggregates (Delphi)

> [!Note]
> This demo is available in your FlexCel installation at ***&lt;FlexCel Install Folder>*\\Demo\\Delphi\\Modules\\20\.Reports\\46\.Aggregates** and also at [https:&#8203;//&#8203;github.&#8203;com/&#8203;tmssoftware/&#8203;TMS-&#8203;FlexCel.&#8203;VCL-&#8203;demos/&#8203;tree/&#8203;master/&#8203;Delphi/&#8203;Modules/&#8203;20.&#8203;Reports/&#8203;46.&#8203;Aggregates](https://github\.com/tmssoftware/TMS\-FlexCel\.VCL\-demos/tree/master/Delphi/Modules/20\.Reports/46\.Aggregates)


## Overview


FlexCel allows you to aggregate tables on the fly, providing you with
the sum, average, maximum or minimum of the records in a table.

> [!Note]
> 
> You will normally **not** want to use in-memory aggregates,
> since they are slower and consume more memory than aggregates made
> directly in the database. (using an expression like \"select sum(field1)
> from table group by field2\")


## Concepts

- Different ways to use the **\<\#aggregate\>** tag to aggregate the
  values in a table.
