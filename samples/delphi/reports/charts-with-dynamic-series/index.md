# Charts With Dynamic Series (Delphi)

> [!Note]
> This demo is available in your FlexCel installation at ***&lt;FlexCel Install Folder>*\\Demo\\Delphi\\Modules\\20\.Reports\\75\.Charts With Dynamic Series** and also at [https:&#8203;//&#8203;github.&#8203;com/&#8203;tmssoftware/&#8203;TMS-&#8203;FlexCel.&#8203;VCL-&#8203;demos/&#8203;tree/&#8203;master/&#8203;Delphi/&#8203;Modules/&#8203;20.&#8203;Reports/&#8203;75.&#8203;Charts With Dynamic Series](https://github\.com/tmssoftware/TMS\-FlexCel\.VCL\-demos/tree/master/Delphi/Modules/20\.Reports/75\.Charts%20With%20Dynamic%20Series)


## Overview


Examples of how to create a chart with one series per row. **Charts with one series per row are not a common thing to do.** You will normally want your series in columns, as shown in the example [Charts](~/samples/delphi/reports/charts/index.md). Even for this demo, the charts would probably look better if we had them with one series per column. But if you need to do it, you can use this example as a base.

## Concepts

- How to use [swap series](~/guides/reports-tag-reference.md#swap-series) to create a chart with a series per row, as explained in [Creating charts with dynamic series](xref:ReportsDesignerGuide#creating-charts-with-dynamic-series).

- To use &lt;#swap series> in an embedded chart, you name the chart with a name containing &lt;#swap series>.The tag will be removed from the final chart name. To use &lt;#swap series> in a chart sheet, you write it on the sheet name. And again, the tag will be removed from the final sheet name.

- How to use the [TFlexCelReport.CustomizeChart](~/api/FlexCel.Report/TFlexCelReport/CustomizeChart.md) event to further customize the chart.
